# 🎮 Гра «Вгадай число»

## 📌 Опис
«Вгадай число» — це проста гра на Python з графічним інтерфейсом Tkinter. Комп'ютер загадує випадкове число від 1 до 10, а гравець повинен його вгадати.

## 🛠️ Використані технології
- Python
- Tkinter — створення графічного вікна
- Random — генерація випадкового числа
- If / elif / else — перевірка відповіді
- Try / except — обробка помилок

## 🎯 Як грати
1. Запусти програму.
2. Введи число від 1 до 10.
3. Натисни кнопку «Перевірити».
4. Прочитай підказку: число більше або менше.
5. Продовжуй, поки не вгадаєш правильне число.
